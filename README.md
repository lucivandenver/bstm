# BSTM CareerBridge

XianFire / Express / Sequelize / MySQL learning and career exploration portal for graduating BSTM students at MinSU Bongabong Campus.

The Student portal includes profiling, course enrollment, sequential lessons and quizzes, knowledge diagnostics, course attempt history, downloadable certificates and badges, credential verification, notifications, skills-gap views, transparent career pathways and optional Gemini guidance. Faculty course drafting supports Admin-selected Gemini, Groq, or Vertex AI. Google signup/sign-in is supported after OAuth configuration.

See [Student setup](docs/STUDENT_SETUP.md) for Laragon installation, safe migration, Google credentials, Gemini configuration and validation instructions. [Vertex AI setup](docs/reviews/VERTEX_AI.md) covers both Express Mode and service-account authentication for course drafting. Admin controls and separate Student/Faculty registration are documented in [Admin and account setup](docs/ADMIN_ACCOUNTS.md). Full course authoring, source-based AI drafts, practical rubrics and role-specific monitoring are documented in [Learning portals release](docs/LEARNING_PORTALS.md). Four optional starter courses are included for testing.
